# Quiz questions and scoring

Answer scores are A = 3, B = 2, C = 1 and D = 0.

- A. Still comfortable, and some already went into savings.
- B. A little left. We’re going to make it.
- C. Almost empty, but payday is close.
- D. My account has already entered next month.
